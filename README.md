# Alferd-party planner agent
The agent is build using smolagents ( a library of hugging face)


## Key Features

<b>LLM Powered</b> : used <B>OpenAIModel</B> configured with an API-compatible provider<br><br>
<b>Custom tool</b> : built with custom function using @tool decorator:((python function ma @tool decorator include gareyou vaney teslai tool vanxa)<br><br>
     <b> suggest_menu</b> - Recommends party menus based on the event's theme/occasion.<br><br>
<b>Time calculation</b> : Integrated with python built-in function 'datetime' module to assist with timing and scheduling calculations.<br><br>
